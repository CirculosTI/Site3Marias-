Atenção, Administrador!

Para a funcionalidade de Pedidos (Checkout) funcionar, você precisa criar duas tabelas no seu Supabase:

  • pedidos (id, created_at, cliente_id (uuid, FK para auth.users), total (numeric), status (text, default 'Pendente'))
  • itens_pedido (id, created_at, pedido_id (uuid, FK para pedidos), foto_id (uuid, FK para fotos), preco_no_momento (numeric))

Certifique-se de ativar o RLS (Row Level Security) para elas.
